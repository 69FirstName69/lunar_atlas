# lunar_atlas

# Лунный атлас

Интерактивный сайт о Луне. Мой первый проект в вайбкодинге.

[Открыть Лунный атлас](https://69firstname69.github.io/lunar_atlas/)

## Что внутри

- **Луна в движении.** На первом экране она плавно вращается при прокрутке. Для поверхности использована текстура 4096 × 4096.
- **Восемь фаз.** Можно переключать фазы и смотреть, как меняется освещение лунного диска.
- **История исследований.** Раскрывающиеся записи о миссиях «Луна-2», «Аполлон-11» и «Аполлон-17».

## Как запустить локально

Скачайте `index.html` и откройте его в браузере. Стили, скрипты, шрифт и текстуры встроены в файл. Сайт сделан на HTML, CSS и JavaScript с использованием Canvas и WebGL.
